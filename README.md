# MovieRecommendationSystem
Super excited to share my latest machine learning project: a **Movie Recommendation System** that suggests movies based on a user’s search preferences. 🍿✨  

### 🔍 **Project Highlights:**  
👉 **Dataset**: Used a Kaggle dataset containing two datasets — **movies data** and **movie credits data**  
👉 **Data Processing**:  
   - Merged both datasets and performed extensive preprocessing on the dataframe.  
   - Extracted relevant fields from features with lists of dictionaries.  
   - Created a **movie tag feature** by combining key information like **movie description, cast, crew**, etc.  

👉 **Natural Language Processing (NLP)**: Used **NLTK** for stemming and converted tags into a vector format.  
👉 **Cosine Similarity**: Calculated similarity between movies using cosine similarity to recommend movies that are closely related to the user’s search. 🎯  

💡 The result? A personalized movie recommendation system that makes finding your next favorite movie easier than ever!
